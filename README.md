# nanochat fork for sm120 GPUs

**NOTE: This is a fork of the nanochat repo:** https://github.com/karpathy/nanochat

Nanochat targets datacenter H100 (sm90) GPUs. This fork targets consumer/workstation Blackwell GPUs (sm120). These sm120 GPUs will no doubt be slower. However, the questions that I was curious about:

- Are there blackwell specific features that can increase performance?
- How does 8x H100 performance compare against 8x RTX Pro 6000 Blackwell?
- How does the rental cost compare? (eg, cheaper/hour but how many more hours are needed?)

This fork is a learning exercise.
